# 私聊天气定时推送设计

## 目标

为 QQ 私聊用户提供每天 08:00 的城市天气预报与出行建议。用户通过私聊命令设置城市，机器人调用 Jarvis 查询当天预报，并将结果作为 QQ 可直接显示的普通文本发送；允许 emoji 和符号表情，但不使用 Markdown。

## 用户交互

- `#天气 杭州`：保存或更新当前私聊用户的城市，并开启每天 08:00 推送。
- `#天气`：查看当前设置的城市和每天 08:00 的推送状态。
- `#天气 关闭`：删除当前私聊用户的城市设置并关闭天气推送。
- 群聊不展示、不注册、不处理天气命令。
- 城市参数去除首尾空白后不能为空；无效命令返回简短用法提示。

## 状态与持久化

新增独立的天气订阅状态，保存 `QQ 用户 ID -> 城市` 映射。天气订阅不复用现有资讯推送订阅，避免天气开关影响微博、华尔街、36 氪和财新等功能。

状态采用并发安全访问，并沿用现有本地 JSON 与腾讯 COS 缓存方式持久化。机器人启动时加载天气状态，更新城市或关闭订阅时立即保存，进程退出时随其他状态再次保存。

## 定时任务与数据流

机器人启动时注册每天 08:00 执行的天气任务，使用 Asia/Shanghai 运行时区。

任务执行流程：

1. 获取天气订阅快照。
2. 按城市分组订阅用户。
3. 每个城市只调用一次 Jarvis，避免相同城市重复查询。
4. 将同一城市的结果分别发送给对应私聊用户。
5. 单个城市查询失败时记录不含敏感信息的错误日志，并向该城市用户发送简短失败提示；不影响其他城市。

## Jarvis 请求

天气查询使用稳定且按城市隔离的 Jarvis 用户身份，避免不同城市的会话互相污染。提示词包含当前日期、城市和明确任务：

- 查询指定城市当天的天气预报。
- 概述天气、最高/最低温、降水、风力和紫外线等可获得信息。
- 给出今日出行、防晒、穿搭建议和注意事项。
- 不虚构无法确认的数据；必要时明确说明信息缺失。
- 只输出适合 QQ 消息的普通文本，可以使用 emoji 和符号表情。
- 禁止 Markdown 标题、列表符号、加粗、代码块、表格和链接语法。

发送前对 Jarvis 答案做轻量 Markdown 清理，移除常见 Markdown 包装字符但保留 emoji，作为提示词约束失效时的兜底。空答案视为查询失败。

## 代码边界

- `coolq/cmd.go`：私聊天气命令注册、帮助文案与处理入口。
- `coolq/state.go`：天气订阅状态、加载与保存。
- `coolq/job.go`、`coolq/bot.go`：08:00 定时任务构造与注册。
- 新增聚焦的天气文件：解析命令、构建 Jarvis 提示词、清理纯文本、查询和私聊发送。
- `docs/CODEX_PROJECT_CONTEXT.md`：同步新增命令、状态和运行流程。

## 验收边界

本次按用户要求不新增自动化测试、不执行本地验证。用户将在更新部署后，通过私聊命令和次日 08:00 定时推送验证实际 Jarvis 与 QQ 消息行为。
